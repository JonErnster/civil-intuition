# Civil Intuition

A public, mobile-first civil engineering concept refresher.

[Open the app](https://JonErnster.github.io/civil-intuition/)

24 original short lessons across forces, structures, soils, water, transportation and construction. Explore SVG schematics with sliders, predict outcomes, reveal equations and model assumptions, then switch to random challenges by difficulty. Progress stays in local storage.

Independent, not affiliated with NCEES or textbook publishers. Not a complete exam course or engineering design tool. No book pages or proprietary problems are included. Topic coverage was informed by a targeted review of the user-owned PE Civil Reference Handbook v1.1 and public references. CERM 14 file located but not text-extracted.

## Run
Open index.html or serve this folder with a static web server. No build or backend. Google Fonts is optional; local font fallbacks apply.

## Accuracy
Each card states its simplifying assumptions and links a reference. Structural idealizations use elementary statics/elasticity; hydraulics uses continuity, Darcy–Weisbach and SI Manning; road models are illustrative kinematics, not design standards. Trench card is a hazard-awareness reminder, not entry authorization.
